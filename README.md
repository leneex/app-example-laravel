# Laravel

Пример приложения [Laravel](https://laravel.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/up` |

На вкладке «Переменные» добавьте `APP_KEY` — ключ шифрования Laravel, без него приложение не
запустится. Сгенерировать его можно в папке проекта:

```bash
php artisan key:generate --show
```

или без PHP: `echo "base64:$(openssl rand -base64 32)"`.

Railpack видит Laravel: ставит PHP 8.4 (версию берёт из `composer.json`), зависимости Composer и
npm, собирает фронтенд и запускает FrankenPHP на порту из переменной окружения `PORT` — её
передаёт платформа. При каждом запуске выполняются миграции. База по умолчанию — SQLite внутри
контейнера, она создаётся заново при каждом деплое; для своего приложения подключите внешнюю базу
переменными `DB_*`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
composer install

# настройки, ключ и база
cp .env.example .env
php artisan key:generate
php artisan migrate

# запуск приложения
php artisan serve
```

Нужен PHP 8.4 или новее и Composer.
