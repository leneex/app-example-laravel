# Laravel

Пример приложения [Laravel](https://laravel.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/up` |

На вкладке «Переменные» добавьте `APP_KEY` — ключ шифрования Laravel, без него приложение не
заработает. Сгенерировать его можно в папке проекта:

```bash
php artisan key:generate --show
```

или без PHP: `echo "base64:$(openssl rand -base64 32)"`.

Railpack видит Laravel: ставит PHP, зависимости Composer и npm, собирает фронтенд и запускает
FrankenPHP на порту из переменной окружения `PORT` — её передаёт платформа. При каждом запуске
выполняются миграции. База по умолчанию — SQLite внутри контейнера, она создаётся заново при
каждом деплое; для своего приложения подключите внешнюю базу переменными `DB_*`.

Версию PHP Railpack берёт из `require.php` в `composer.json`: `^8.5` — это PHP 8.5. В демо нет
`composer.lock` и `package-lock.json`, версии пакетов выбираются при сборке. Если добавите
`composer.lock`, создавайте его на той версии PHP, что указана в `composer.json`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# зависимости, файл .env, ключ, база и сборка фронтенда
composer run setup

# запуск в режиме разработки
composer run dev
```

Приложение откроется на `http://localhost:8000`. Нужны PHP 8.5 или новее, Composer и Node.js 22.13
или новее.
